# 편의점 야간근무 🏪

> 새벽 3시, 혼자 남았다.

브라우저에서 바로 플레이하는 **랜덤 디펜스 웹게임**. 랜덤 유닛을 뽑고, 합성하고, 새벽 편의점으로 몰려오는 손님(과 이상한 사건)을 계산대 앞에서 막아라.

- 장르: 랜덤 디펜스 · 캐주얼 전략 · 로그라이크 · 밈 코미디
- 플랫폼: 웹 (PC 마우스 / 모바일 터치, 가로·세로 반응형)
- 기술: Vite + React + TypeScript, Canvas 2D, WebAudio (외부 에셋 0개, 라이브러리 최소)

---

## 1. 실행 방법

```bash
npm install
npm run dev        # http://localhost:5173
```

## 2. 개발 서버

```bash
npm run dev        # 로컬 + LAN 노출 (--host). 휴대폰에서 같은 와이파이로 접속해 테스트 가능
```

## 3. 빌드

```bash
npm run build      # 타입체크 후 dist/ 생성
npm run preview    # dist/ 를 로컬에서 미리보기 (http://localhost:4173)
```

기타 스크립트:

```bash
npm run typecheck                      # tsc --noEmit
npm run sim -- 20 sellCommons          # 헤드리스 밸런스 시뮬레이션 (20판, 판매 전략)
npx tsx scripts/playtest.ts http://localhost:4173 shots landscape 60   # 브라우저 자동 플레이 + 스크린샷
npx tsx scripts/playtest2.ts http://localhost:4173 shots               # 게임오버/저장/재시작/상점 흐름 검증
```

Playwright 스크립트는 `npx playwright install chromium` 이 필요하다 (또는 `CHROME_PATH=/path/to/chrome` 지정).
브라우저 테스트가 필요 없으면 `PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1 npm install` 로 설치 시간을 아낄 수 있다.

## 4. 배포 방법

정적 파일이므로 어디든 올릴 수 있다. `vite.config.ts` 의 `base: './'` 덕분에 하위 경로에서도 동작한다.

- **Vercel / Netlify**: 저장소 연결 → Build command `npm run build`, Output `dist`. 끝.
- **GitHub Pages**: `npm run build` 후 `dist/` 를 `gh-pages` 브랜치로 푸시 (`npx gh-pages -d dist`).
- **Cloudflare Pages** (아래 §4-1 상세).
- **직접 호스팅**: `dist/` 폴더를 nginx/S3 등 아무 정적 서버에 업로드.

### 4-1. Cloudflare Pages 배포 (권장, 무료)

**방법 A — GitHub 연동 (푸시하면 자동 배포)**

1. https://dash.cloudflare.com → **Workers & Pages** → **Create** → **Pages** → **Connect to Git**
2. 이 저장소(`djkdb/zunran`)와 브랜치를 선택
3. 빌드 설정:
   - Framework preset: **Vite**
   - Build command: `npm run build`
   - Build output directory: `dist`
   - 환경 변수(Environment variables)에 추가: `PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD` = `1` (테스트용 Playwright 가 브라우저를 내려받지 않게 해 빌드 시간을 줄인다), `NODE_VERSION` = `20`
4. **Save and Deploy** → 1~2분 뒤 `https://<프로젝트명>.pages.dev` 주소가 생긴다. 이후 브랜치에 푸시할 때마다 자동 재배포된다.

**방법 B — 명령어 한 줄 (Wrangler)**

```bash
npx wrangler login                 # 브라우저에서 Cloudflare 계정 승인 (최초 1회)
npm run deploy:cf                  # build 후 dist/ 를 Pages 프로젝트 cvs-night-shift 로 업로드
```

처음 실행하면 프로젝트를 새로 만들지 물어보니 Enter. 출력되는 `https://cvs-night-shift.pages.dev` 가 배포 주소다.

**커스텀 도메인**: Pages 프로젝트 → **Custom domains** → 도메인 입력. Cloudflare 에서 관리하는 도메인이면 DNS 가 자동으로 잡힌다.

**확인 사항**: `vite.config.ts` 의 `base: './'` 덕분에 추가 설정 없이 동작한다. SPA 라우팅이 없으므로 `_redirects` 도 필요 없다. HTTPS 는 기본 제공되어 클립보드 복사(결과 공유) 기능도 정상 동작한다.

친구에게 링크만 보내면 설치 없이 바로 플레이된다. 모바일은 "홈 화면에 추가"로 앱처럼 실행 가능.

## 6. 게임 시스템 설명

**핵심 루프**: 뽑기(코인) → 배치 → 자동 공격 → 손님 웨이브 → **보상 3택 1** → 같은 유닛 3개 합성 → 더 강한 손님 → 보스 → 생존 시간 기록.

- **웨이브 보상 3택 1 (로그라이크)**: 3웨이브마다, 그리고 보스 직후에 게임이 멈추고 카드 3장 중 하나를 고른다. 19종이 있고 한 판 동안 유지된다. 공격력·공격속도·사거리·코인·치명타 같은 누적 강화, 유닛 즉시 지급, 티어 상승, 체력 회복, 무료 뽑기, 그리고 "새벽 장사"(다음 웨이브 손님 2배·코인 2배) 같은 도박 카드까지. 같은 카드를 또 고르면 다음부터 등장 확률이 낮아진다.
- **긴급 스킬 2종**: [셔터 내려](45초 쿨) 손님 전원 2.5초 정지 + 뒤로 밀기, [폐기 처리](70초 쿨) 화면 전체 피해. 위기 탈출용이자 손이 심심하지 않게 하는 조작.
- **코너 배치 보너스**: 진열대 줄마다 특성이 다르다. 음료 코너 사거리 +18, 과자 코너 공격속도 +12%, 라면 코너 공격력 +22%. 어느 줄에 둘지가 전략이 된다.
- **연속 처치 콤보**: 2.2초 안에 이어서 처치하면 콤보가 쌓이고 5연쇄마다 보너스 코인이 터진다 (최대 4배).
- **밤이 깊어질수록 빨라진다**: 웨이브 간격이 22초에서 14초까지 줄어든다.

- **필드**: 640×640 논리 좌표의 편의점. 손님은 입구(좌상) → 음료 코너 → 과자 코너 → 라면 코너 → 계산대(S자 경로)로 이동. 계산대 도달 시 편의점 체력 감소. 진열대 3줄 × 7칸 = 21 슬롯에 유닛 배치.
- **뽑기**: 100원 시작, 뽑을 때마다 +10원(최대 420). 일반 60 / 희귀 28 / 에픽 10 / 전설 2%. 뽑은 유닛은 빈 슬롯에 자동 배치. 유닛 탭 → 빈 칸 탭 = 이동, 다른 유닛 탭 = 교환.
- **유닛 15종**: 일반(삼각김밥·야간 알바생·라면 진열대·냉장고), 희귀(포스기·커피머신·CCTV·청소기·아이스크림 냉동고), 에픽(전자레인지·로또 기계·택배 접수기), 전설(점장), 특수·합성 전용(편의점 고양이·10년차 알바). 각 유닛은 공격 방식/타겟팅/명중 효과/오라/스킬을 가진다.
- **합성**: 같은 유닛·같은 티어 3개 → 70% 티어+1, 25% 상위 희귀도 랜덤 유닛(같은 티어), 5% 특수(점장 또는 특수 유닛). 티어당 피해 ×3.4. 최대 5티어.
- **손님 18종 + 보스 4종**: 기본/담배(빠름)/술취한(비틀거림)/가격(멈춰서 뒤를 막음)/라면(라면 코너에서 머물며 강해짐)/배달기사/단체/술 취한 친구들(뭉쳐 이동)/봉투(처치 시 봉투값 요구)/새벽 3시 진상(WARNING)/충전기(유닛 마비)/택배(탱커)/화장실(맞으면 가속)/사장님 불러(주변 가속)/유령(깜빡임)/좀비(후반). 보스: 10 폐기 직전 도시락, 20 새벽 3시 단체 손님, 30 본사 직원, 40 월말 매출 마감 (이후 순환).
- **웨이브**: 22초에서 시작해 웨이브마다 0.22초씩 짧아진다(최소 14초, 보스 36초). 1~3웨이브는 학습용. 웨이브 13 = 03:00 "새벽 3시입니다" 20명 러시. 체력 스케일 `1 + 0.16w + 0.05w²`(40 이후 ×1.07/웨이브), 계산대 도달 피해도 웨이브마다 6%씩 증가. 웨이브 시작마다 시급(40+9w원) 지급, 웨이브 클리어(손님 전원 처리) 시 보너스.
- **랜덤 이벤트 23종**: 웨이브 3부터 32~48초마다. 손님 몰림/정전/비/1+1 행사/본사 점검/배달 폭주/사장님 전화/길고양이 등.
- **연출**: LEGENDARY 풀스크린 배너 + 흔들림 + 플래시, WARNING 배너, 보스 인트로, NEW RECORD, 로또 1등, 손님 말풍선(밈 대사), 정전 시 손전등 효과, 비 오는 연출.
- **메타**: 한 판 종료 시 야간 수당(코인의 10% + 웨이브·처치 보너스). 시작 코인/초기 체력/뽑기 할인/희귀 확률/에픽·전설 확률/코인 획득량 각 5레벨.
- **저장**: `localStorage["cvs-night-shift:v1"]` 에 최고 웨이브/최장 생존/총 플레이/도감/메타/음소거.
- **비주얼 방향 (간판 스타일)**: 한국 편의점 간판·가격표의 시각 언어. 납작한 원색 블록(먹색·종이·간판 블루·경고 빨강·가격표 노랑), 모서리 반경 0, 2~3px 먹색 키라인, blur 0 단색 오프셋 그림자. 그라데이션·글로우·이모지 아이콘을 쓰지 않고 SVG 아이콘(`src/ui/Icon.tsx`)과 눈금형 티어 표시를 쓴다. 글꼴은 Black Han Sans(숫자·큰 제목) + Gothic A1(본문). 시안과 규격은 `design/` 참고.
- **조작**: 탭/클릭. 키보드 `D` 뽑기, `Space` 일시정지, `Esc` 선택 해제. ×2 배속, 자동 합성 토글, 🧹 정리(짝 없는 ★1 일반 유닛 일괄 판매) 버튼. 첫 판에는 뽑기→합성→이동 힌트가 뜬다. 게임오버 화면에서 결과를 클립보드로 복사해 공유할 수 있다.

**밸런스 검증 (헤드리스 시뮬레이션, 20시드)**: 사람에 가까운 전략(보상은 등급 높은 카드 선택, 몰리면 긴급 스킬) 기준 사망 웨이브 중앙값 43 (최소 24), 합성을 안 하면 중앙값 24, 뽑기만 남발하면 33, 메타 업그레이드 만렙이면 최대 75까지. 20웨이브부터 체력이 조금씩 깎이기 시작해 40웨이브 보스가 분명한 벽이 된다.

## 7. 추후 추가하면 좋은 기능

- 도전 모드: "전설 금지", "일반 유닛만", "냉장고 챌린지" 등 릴스용 제약 모드
- 유닛 스킨/편의점 브랜드 테마, 계절 이벤트 손님
- 튜토리얼 힌트 강화(첫 판 한정 말풍선), 설정(진동/그래픽 품질)

## 8. 릴스 제작에 가장 좋은 플레이 장면 10개

세로(9:16) 모바일 화면이 기본 촬영 구도다. 콘솔에서 `__game.engine` 으로 상태를 조작해 장면을 연출할 수 있다.

1. **첫 뽑기에서 전설** — 풀스크린 `LEGENDARY` + "점장이 출근했습니다." + 화면 흔들림·금색 플래시. (`__game.engine.state.rng.next = () => 0` 후 뽑기)
2. **새벽 3시입니다** — 웨이브 13 시작 시 붉은 배너와 20명 러시 + WARNING 진상 등장. 화면이 손님으로 가득 찬다.
3. **체력 1%에서 보스 처치** — 붉은 비네팅 펄스 + 보스 체력바 + "처리 완료" 배너. (`state.hp = 1`)
4. **합성 ????? 특수 결과** — 합성 시 5% 로 편의점 고양이/10년차 알바가 튀어나오는 순간의 배너·폭발 파티클.
5. **로또 1등!!!** — 로또 기계 2% 치명타 25배 피해. 금색 배너 + 큰 숫자 플로터.
6. **점장 등장으로 전황 역전** — 계산대 앞까지 밀린 상태에서 점장 잔소리 스킬("야! 정신 안 차려?!")로 한 방에 정리.
7. **정전 이벤트** — 화면이 어두워지고 유닛 주변만 손전등처럼 밝은 상태에서 손님이 밀려오는 장면.
8. **월말 매출 마감 보스** — 40웨이브, 보호막 페이즈 + 코인이 줄어드는 연출, "숫자가 맞지 않는다".
9. **냉장고/CCTV만으로 버티기** — "편의점에서 가장 쓸모없는 물건만 뽑아봤습니다" 컨셉. 공격 유닛 없이 감속 오라만으로 손님이 기어가는 화면.
10. **NEW RECORD + 영업 종료 통계 카드** — 신기록 배너 후 "이번 야간근무에서 처리한 손님: N명", MVP 유닛, 야간 수당 획득까지 한 컷.

보너스: 술 취한 손님이 뒤로 비틀거리며 "사장님… 사랑해요" 말풍선, 봉투 손님이 죽으면서 "봉투값 20원 주세요", 좀비 손님 "으어어… 컵라면…" 등 밈 말풍선 모음 컷.
